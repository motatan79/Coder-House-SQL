# DESCRIPCIÓN DEL PROYECTO
El proyecto consiste en la creación de una base de datos llamada retail_project, con tablas de clientes, productos y ventas, considerando ciertas restricciones relacionadas con claves primarias,
foráneas, tipo de dato, etc. 

Objetivo: Extraer inteligencia de negocio combinando múltiples tablas mediante JOINs, GROUP BY y HAVING.
